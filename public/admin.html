Fares you've seen yourself

A fare you type here does not become the price on the board. It joins the evidence the estimate is built from — the same thing a paid live lookup does — and pulls that route's estimate toward it. The result is still labelled an estimate, because that is still what it is. Say whether what you saw was the cheap end, the usual, or the expensive end, and it informs that end of the range rather than all three.

The attraction list

What each resort has, which is how the board can tell somebody that only Shanghai has Zootopia. The list below is what the app is using right now. The rows it shipped with are a starting point, not a researched catalogue — changing one here takes effect immediately, with no deploy.

List every resort that has it. “Only here” is never something you tick: it is worked out from how many resorts you name, so adding Paris to Ratatouille automatically stops the app claiming EPCOT is the only place to ride it. A ride with a different name abroad is still the same ride — put both resorts on one row and explain the difference in the note.

Lands and rides both belong here. Set the type to land for a whole themed area (Cars Land, Zootopia) and attraction for a ride or show. The land column says where it sits at each resort, as wdw: Liberty Square; dlr: New Orleans Square. Hide keeps a row but takes it off the traveler's list, so you choose what's shown without losing anything you typed.

Wait times we've recorded

Every two hours a job reads each park's posted waits from Queue-Times and keeps the ones taken between 9am and 7pm local time. Travelers never see this: posted waits run long, and not by the same amount at every resort. It's an archive, saved so there's a year of history to judge by when the time comes. A park showing nothing recorded, or nothing in the last day, is one to tell Claude about.
